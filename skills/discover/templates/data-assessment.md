## Feasibility Grade: [A / B / C / D / F]

The grade measures **access effort**, not overall fit. Fit is what the explorer-critic's
categories score; grading both on one letter made an inaccessible perfect dataset and an
accessible mediocre one indistinguishable.

- A: Ready to use -- public download, documented, standard format
- B: Accessible with effort -- application required, moderate cost, needs cleaning
- C: Restricted but obtainable -- FSRDC, data use agreement, IRB approval
- D: Very difficult -- proprietary, requires partnership, rare access
- F: Not obtainable for this project -- goes in the rejection table

## Critique

The explorer-critic scores these six categories
(`.claude/skills/review/templates/data-review-6-categories.md`):

1. **Measurement validity:** Does the variable actually measure what we need?
2. **Sample selection:** Who is in the data? Who is missing?
3. **External validity:** Can we generalize from this sample?
4. **Alternative data sources:** Is there a better dataset that was missed?
5. **Practical feasibility:** Access timeline, computational resources, IRB/ethics.
6. **Identification compatibility:** Does this data support the proposed design?
