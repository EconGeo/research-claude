NOTES

NOTE 1 — WHY THE INVENTORY IS A UNION, NOT `check_paths --list` ALONE.
  check_paths.py's PATH_RE opens with a negative lookbehind `(?<![A-Za-z0-9_./-])`, so a
  reference that begins mid-path is invisible to it. Every agent file writes its bundled
  resources skill-relative — `analyze/templates/pre-code-report.md`,
  `strategize/templates/decision-record.md`, `review/templates/code-review-16-categories.md`
  — and the character before `templates/` is `/`, which the lookbehind rejects. Thirty of
  these live in agents/coder.md, agents/strategist.md, agents/writer.md and the five critics.
  audit_graph.py's PATH_RE has no lookbehind and sees all of them. An inventory built from
  `check_paths --list` alone would omit them, Stage 3b would never rewrite them, and Task
  3b.8's `dangling = 0` would fail at the end of a long stage with no obvious cause.

NOTE 2 — READ THE TOTALS WITH `grep '^total='`, NOT `tail -1`.
  check_paths.py prints the totals line BEFORE its PASS/FAIL line and before the vendored
  WARN rows, so `tail -1` lands on a WARN row about submodules/ai-audit.
